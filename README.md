# 项目简介

## 核心功能
- 管理员端
  - 客房类型管理
  - 酒店客房管理
  - 客房预定管理
  - 入住登记
  - 续订服务
  - 退房处理
  - 留言反馈
  - 系统设置
  - 个人资料管理
  - 用户管理
- 用户端
  - 客房预订
  - 入住登记
  - 续订服务
  - 退房处理
  - 个人资料管理

## 适用场景
- 酒店行业
- 旅游业
- 客房预订服务提供商

## 技术特点
- 采用Python语言开发
- 基于Django框架构建
- 数据存储使用MySQL数据库
- 提供用户友好界面，便于操作和管理
